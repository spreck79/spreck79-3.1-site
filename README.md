# Spreck79 3.1 — web edition

All side quests. No main story.

A Prairie-style retro desktop with its own command line, S79DOS, running right in the browser.

**Play it:** https://os.spreck79.com

- It boots into S79DOS first, then starts the desktop. Press F8 while it boots to stay at the `C:\>` prompt.
- Type `HELP` at the prompt to list the commands.
- Files you save live in your own browser and stay there until you clear its site data.

This repo holds only the published website. The source and the Windows exe build live in the main Spreck79 3.1 repo. Changes made there are copied here with `npm run site`.
